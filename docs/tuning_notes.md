# 参数调优笔记（tuning_notes.md）

> 方法论：**先定位后规划**；一次只改一个参数；记录"参数/旧值/新值/场景/现象/结论"；
> 分场景回归（直道、窄门、绕障、动态人墙、墙角目标）；失败录 rosbag 复盘。
> 本文件按改动倒序追加，每条都要有前后对比。

## 模板

```
### [日期] 参数名：旧值 → 新值
- 场景：（直道 / 窄门 / …）
- 现象：（改之前什么样，改之后什么样）
- 结论：（保留 / 回滚 / 继续观察）
```

---

### [YYYY-MM-DD] local_costmap.inflation_radius：0.45 → 0.40
- 场景：宽 0.9m 窄门
- 现象：0.45 时全局路径不进门（膨胀把门堵死）；0.40 后可过，贴门框单侧余量约 5cm
- 结论：保留 0.40；门宽量出实测值后再收 0.35

### [YYYY-MM-DD] general_goal_checker.xy_goal_tolerance：0.15 → 0.10
- 场景：5 点巡航精度验收
- 现象：0.15 时卷尺实测 P95≈12cm 不达标；收到 0.10 后 P95≈8cm，到点有轻微摆头
- 结论：保留 0.10；摆头靠 yaw_goal_tolerance=0.08 + 降 max_vel_x 缓解
